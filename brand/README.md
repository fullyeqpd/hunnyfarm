# Hunny Farm brand files

The logo is a round seal: "HUNNY FARM" around the top (Cormorant Garamond SemiBold), "SPECIALTY HONEY" around the bottom (Instrument Sans SemiBold), the bee in the middle. Text is drawn as outlines, so the SVGs need no fonts installed.

| File | Use |
|---|---|
| `seal-gold.svg` / `seal-gold-2048.png` | Primary. Gold #F0C12E disc, ink #2A1A10. Profile pictures, labels, anywhere on cream or white. |
| `seal-ink-on-cream.svg` / `-2048.png` | One color, ink on cream #FAF6EC. Print, stamps, receipts. |
| `seal-cream-on-ink.svg` / `-2048.png` | One color, cream on ink. Dark backgrounds. |
| `seal-ink-transparent.svg` / `-2048.png` | Ink lines only, no disc. Stamp onto any honey-color band or illustration. |
| `seal-cream-transparent.svg` / `-2048.png` | Cream lines only, no disc. Stamp onto dark or saturated backgrounds. |

Rules: never redraw, retype, recolor (beyond the versions above) or add words to the seal. Minimum size 32 px on screen; below 48 px the ring text is decorative, that is expected. Keep clear space of at least the ring width around it. Colors: cream #FAF6EC, paper #FFFDF7, ink #2A1A10, clover gold #E9A93B, linden yellow #F0C12E, tupelo amber #C9712B, florida red #7B2912.

Fonts (variable TTFs, OFL) are in `fonts/` for tools that need them; `../brand/build` is not required to use the assets.
